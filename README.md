# LLMOps 02 — LLM Observability

A deep-dive presentation on observability for production LLM systems: why LLM tracing differs from conventional distributed tracing, trace structure (request, completion, tool calls, sub-spans), OpenTelemetry GenAI semantic conventions, and a practical comparison of Langfuse, Arize Phoenix, Helicone, and LangSmith.
